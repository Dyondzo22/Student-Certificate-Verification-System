# Student Certificate Verification System

A blockchain-based decentralized application (DApp) that enables educational institutions to issue secure digital certificates and allows employers and other organizations to verify certificate authenticity using Ethereum smart contracts.

## Features

- Issue digital student certificates
- Verify certificate authenticity
- Prevent certificate fraud
- Store certificate records on the Ethereum blockchain

## Technologies

- Solidity
- Ethereum
- Git
- GitHub
- Visual Studio Code
